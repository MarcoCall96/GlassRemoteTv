# AGENTS.md
Instructions for AI coding assistants (Claude, Copilot, Codex, Cursor...) helping a user install the TV app from the `AppTv/` folder of this repository.
The full guide is in **[CLAUDE.md](CLAUDE.md)** (English) and **[CLAUDE.it.md](CLAUDE.it.md)** (Italiano). Read it first.
Short version: reply in the user's language, one step at a time, and let the user do every step on the TV.
Never open router ports. Never ask for, store or print the PIN or any secret.
Get the user's explicit OK before they turn on network debugging. Use only the user's own TV and network.
